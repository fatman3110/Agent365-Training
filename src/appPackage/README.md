# appPackage/color.png / appPackage/outline.png

Teams App Package のアイコン画像。**プレースホルダーを本リポジトリに同梱済み**なので、まずはそのまま `manifest.json` を使ってよい。

- `color.png` — 192×192px のフルカラーアイコン（プレースホルダー：単色＋頭文字）
- `outline.png` — 32×32px の透過（白線・透明背景）アイコン（プレースホルダー：白い円）

本番公開前や見た目を変えたい場合は、任意の画像編集ツール／アイコン生成サイトで作り直すか、
`docs/../assets/` 配下の既存アイコンをリサイズして差し替えてよい（Teams のアイコン要件は
[Learn: アプリのアイコン](https://learn.microsoft.com/microsoft-teams/platform/concepts/build-and-test/apps-package#app-icons) を参照）。
